Gilt nur für Endverbraucher im Shop looxis.de (www.looxis.de). Die Codes gelten nicht auf Amazon und nicht für Fachhändler, LOOXIS-Pro oder masterpics.

Testweise gültig bis 31.03.2027: Bis dahin werden die Codes auf Aktualität geprüft.

# Regel

Ein Rabattgutschein wird nur genannt, wenn der Mitarbeiter ihn ausdrücklich verlangt (zum Beispiel „10% Rabattgutschein“ im Feld „Zusätzliche Informationen“). Die Höhe bestimmt der Mitarbeiter. Von sich aus bietet die Antwort keinen Rabattcode an und schlägt keine Höhe vor.

Gültige Rabattcodes:

- 10 % Rabatt: KWEBT86LME
- 20 % Rabatt: HTME34PLER
- 30 % Rabatt: PLER79HTME

Verlangt der Mitarbeiter einen Rabatt in einer dieser Höhen, wird genau der zugehörige Code eingefügt, zusammen mit der Erklärung zur Einlösung (siehe „Kommunikation“). Andere Prozentsätze gibt es nicht; ein Code darf nie erfunden oder abgewandelt werden.

# Bedingungen der Rabattcodes

- Der Code muss im Bestellprozess angewendet werden. Eine nachträgliche Einlösung oder eine Gutschrift ist grundsätzlich nicht möglich.
- Der Code ist nicht mit anderen Gutscheinen kombinierbar.
- Der Code ist einmalig einlösbar.
- Der Code ist maximal 10 Tage gültig.

# Einlösung im Shop

1. Auf www.looxis.de das Produkt auswählen, konfigurieren und in den Warenkorb legen.
2. Auf „zur Kasse gehen“ klicken.
3. Auf der Seite „Bestellung abschließen“ (Kasse) unter der Gesamtsumme den Gutscheincode eingeben und auf „anwenden“ klicken.
4. Die Gesamtsumme wird sofort reduziert.

# 5-Euro-Willkommensgutschein erneut mitteilen

Wer im Shop looxis.de ein Kundenkonto anlegt und es über den Link in der Bestätigungsmail verifiziert, erhält automatisch einen 5-Euro-Gutschein (siehe POLICY-051). Das dient zugleich der Prüfung, ob die E-Mail-Adresse stimmt und Mails ankommen.

Manchmal erreicht den Kunden dieser Code nicht (E-Mail gelöscht, im Spam-Ordner o. Ä.). Dann kann der Code erneut mitgeteilt werden:

- 5 Euro Gutschein: PXMTEZ5AWG
- Voraussetzung: Der Warenkorbwert beträgt mindestens 10 Euro.

# Gilt nicht wenn

- Der Kunde bestellt auf Amazon oder gehört zu Fachhändler, LOOXIS-Pro oder masterpics.
- Der Mitarbeiter hat keinen Rabattgutschein verlangt und der Kunde hat auch keinen Willkommensgutschein vermisst. Dann wird kein Code genannt.
- Der Kunde möchte einen Rabatt oder eine Gutschrift auf eine bereits abgeschlossene Bestellung. Dafür ist der Code nicht gedacht; eine Entscheidung darüber trifft der Mitarbeiter.

# Kommunikation

Zu jedem genannten Code gehört die kurze Erklärung zur Einlösung, zum Beispiel:

„Mit dem Gutscheincode [CODE] erhalten Sie [10/20/30] % Rabatt auf Ihre nächste Bestellung. So lösen Sie ihn ein: Wählen Sie unter www.looxis.de Ihr Produkt aus, konfigurieren Sie es und legen Sie es in den Warenkorb. Klicken Sie anschließend auf ‚zur Kasse gehen‘. Auf der Seite ‚Bestellung abschließen‘ können Sie unter der Gesamtsumme den Gutscheincode eingeben. Klicken Sie auf ‚anwenden‘, die Gesamtsumme wird sofort reduziert. Bitte beachten Sie: Der Code muss im Bestellprozess angewendet werden, eine nachträgliche Einlösung oder Gutschrift ist nicht möglich. Er ist nicht mit anderen Gutscheinen kombinierbar, nur einmal einlösbar und maximal 10 Tage gültig.“

Beim 5-Euro-Gutschein lautet die Erklärung entsprechend, mit dem Hinweis auf den Mindestwarenkorbwert von 10 Euro.

# Grenzen

- Keine Codes oder Prozentsätze nennen, die nicht in dieser Policy stehen.
- Keine Bedingungen erfinden (Mindestbestellwert der Rabattcodes, Produktausschlüsse, Verlängerung der Gültigkeit).
- Die Codes nicht ungefragt anbieten und nicht als Ersatz für eine Erstattung, Kulanz oder Neuanfertigung vorschlagen.
